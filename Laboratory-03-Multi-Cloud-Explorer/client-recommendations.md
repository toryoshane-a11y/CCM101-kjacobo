# Client Recommendations

## Client A – Startup Company
**Recommended Cloud Platform:** AWS

I would choose AWS because it has many services that can help the company create and run its mobile app. It is also good for startups because they can start small and increase their resources as the app gets more users. AWS has flexible pricing, which can help them stay within their budget.

**Services:**
- Amazon EC2 – Runs the application.
- Amazon S3 – Stores files and images.
- Amazon RDS – Stores and manages the database.

## Client B – University
**Recommended Cloud Platform:** Microsoft Azure

I would choose Microsoft Azure because the university already uses Microsoft products. Azure works well with Windows Server, Microsoft 365, and Active Directory. This would make it easier for the university to move some of its services to the cloud.

**Services:**
- Azure Virtual Machines – Runs servers and applications.
- Microsoft Entra ID – Manages users and accounts.
- Azure Blob Storage – Stores files and data.

## Client C – AI Research Company
**Recommended Cloud Platform:** Google Cloud Platform (GCP)

I would choose Google Cloud because it is strong in AI and Machine Learning. It has tools that can help the company build and run AI applications. It also provides powerful computing resources for research.

**Services:**
- Google Compute Engine – Provides virtual machines.
- Vertex AI – Used for AI and Machine Learning.
- Google Kubernetes Engine (GKE) – Manages applications using containers.

## Client D – Global E-Commerce Company
**Recommended Cloud Platform:** AWS

I would choose AWS because it can support customers from different parts of the world. AWS can also automatically increase resources when there are many users visiting the website. This makes it a good choice for an online shopping company.

**Services:**
- Amazon EC2 – Runs the website and application.
- Amazon S3 – Stores product images and files.
- Amazon RDS – Manages customer and product data.
- Elastic Load Balancing – Helps distribute website traffic.




## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Has many services and flexible pricing for small businesses. |
| Enterprise Organization | Azure | Works well with large companies and enterprise tools. |
| Microsoft Environment | Azure | Integrates easily with Microsoft products like Windows and Office. |
| AI / Machine Learning | GCP | Has strong AI and machine learning services. |
| Kubernetes Deployment | GCP | GKE makes it easy to deploy and manage Kubernetes. |
| Global Web Application | AWS | Has a large global infrastructure and many regions. |
