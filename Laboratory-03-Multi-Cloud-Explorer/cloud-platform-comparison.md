| Storage Service | Amazon S3 | Azure Blob Storage | Google Cloud Storage |

| Identity Service | AWS IAM | Microsoft Entra ID | Google Cloud IAM |
| Primary Strength | Large range of cloud services | Microsoft integration | AI, data analytics, and Kubernetes |
| Ideal Organizations | Large businesses and startups | Businesses using Microsoft products | Data-focused and technology companies |

## Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of cloud services. It has a very large selection of tools for computing, storage, databases, networking, AI, and more.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure is the best choice for organizations that already use Microsoft products. It works well with tools such as Windows Server, Microsoft 365, and Active Directory.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud is especially strong in AI, machine learning, and Kubernetes. Google originally created Kubernetes, so it has strong support for container-based applications.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS because it offers many different services and is widely used by businesses. I also think it would be useful to learn because AWS skills are commonly needed in cloud-related jobs.
