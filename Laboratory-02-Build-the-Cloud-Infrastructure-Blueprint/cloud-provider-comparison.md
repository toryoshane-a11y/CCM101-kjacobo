


| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Virtual Private Cloud |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Google Cloud IAM |


1. Which cloud provider offers the broadest range of services? Explain your answer.
AWS offers the broadest range of services among the three providers. It was the first 
major public cloud platform, launched in 2006, which gave it years of head start to 
build out a wide catalog of specialized services covering compute, storage, databases, 
machine learning, IoT, and more. As a result, AWS is often considered the most 
feature-complete cloud platform available today.

2. Which cloud platform would you recommend for an organization that primarily uses 
Microsoft products? Why?
Microsoft Azure would be the best choice for an organization already relying on 
Microsoft products. Azure integrates seamlessly with tools like Windows Server, Active 
Directory, Microsoft 365, and .NET applications, which reduces compatibility issues and 
simplifies identity management through Microsoft Entra ID. This tight integration makes 
it easier for IT teams already familiar with the Microsoft ecosystem to adopt Azure.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine 
Learning (ML), and Kubernetes services?
Google Cloud Platform is widely recognized as the leader in AI, ML, and Kubernetes. 
Google originally developed Kubernetes internally before open-sourcing it, and GCP 
continues to offer strong native support for container orchestration. GCP also provides 
advanced AI/ML tools such as Vertex AI, which are built on Google's own research in 
machine learning.

4. What similarities did you observe among the three cloud providers?
All three cloud providers offer equivalent core infrastructure categories: compute, 
storage, networking, and identity and access management, even though they use different 
service names. They also share a pay-as-you-go pricing model, global data center 
regions for redundancy and low latency, and strong security and compliance certifications. 
This shows that despite branding differences, the fundamental building blocks of cloud 
computing are consistent across major providers.
